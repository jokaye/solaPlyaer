# Sola Player — 开发设计规范（v1，对齐 variants2.html）

> 目标平台：**iOS 原生 SwiftUI**（iOS 17+）
> 视觉基准：`prototype/variants2.html`（蓝/绿天气渐变 · 上半留白 · 下移矮波形 · 微型控件）
> 交互基准：`prototype/index.html`（拖动波形 → 时间跟随 + 跨格微震动 + 快进/倒退方向）
> 说明：以下尺寸基于 **340×720pt 设计稿**，落地时按屏宽等比缩放（`width / 340`）。颜色用十六进制，透明度用百分比。

## 1. 设计原则
1. **上半天气、下半操作**：屏幕上半是大片渐变 + 特大时间码（天气 App 观感），交互元件集中在下半。
2. **波形即进度**：唯一的进度条是波形，竖条高度 = 该时刻响度。
3. **触觉即反馈**：拖动跨"格"轻微震动，控件可以做小。
4. **超轻排版 + 磨砂玻璃**：ultraLight 大字、单色线性图标、`.ultraThinMaterial` 控件。

## 3.5 分组 / 播放列表模型 + 交互流程 ★

### 模型语义（核心：互不干扰）
- **默认列表（Master）**：所有导入的音频**永远**在这里，是"总播放列表"。导入不会自动进任何分组。
- **分组（Group = 命名播放列表）**：默认列表之上的**独立集合**，通过"成员关系"引用音频；**引用而非移动**——加入/移出分组都**不影响**默认列表。
- **成员关系（Membership）**：`(分组, 音频, 组内顺序 order)`。因此支持**每个分组独立的自定义排序**；一个音频可存在于默认列表 + 0..N 个分组（多归属，待确认见 §8）。
- **播放作用域（Scope）**：`默认列表 | 某分组`。**播放时只在当前作用域内取队列并切歌**；换作用域才换队列。

### 交互流程（端到端）
1. **导入**：选择文件夹源/文件 → 拷入 App 容器 → 加入**默认列表**（不进分组）。
2. **分组**：新建分组；在默认列表多选音频「加入分组…」，或从曲目行菜单加入。
3. **组内自定义排序**：进入某分组，右上「编辑」→ 列表出现拖拽把手，`.onMove` 拖拽排序 → 写回该组 `order`（只影响本组）。
4. **编辑分组**：重命名、改颜色/封面、删除分组（**只删集合，音频仍在默认列表**）、拖拽调整分组之间的顺序（chips 顺序）。
5. **取消分组**：在分组内对音频「取消分组」→ 删除该成员关系 → 音频从该分组消失，**仍保留在默认列表**。
6. **选列表播放**：点某个 chip 切换作用域 → 列表刷新为该作用域内容（分组按组内自定义顺序）→ 点任一曲进入播放，队列 = 当前作用域。
7. **播放中显示来源**：PlayerView 顶栏中间常显**当前播放列表名**（默认列表 / 分组名）；上一首/下一首只在该列表范围内循环。

### 边界规则
- 删除音频（从默认列表彻底删除）→ 级联移除其所有分组成员关系与标记。
- **播放队列 = 开始播放时对当前作用域的快照，播放期间固定**：之后即使该分组被删除、或队列内音频被取消分组，**当前队列不变**，「下一首/上一首」继续在这份快照列表里走（不回退默认列表、不中断）。仅当用户主动切换作用域或重新进入某列表播放时才重建队列。
- 唯一例外：队列中的音频被**彻底删除**（从默认列表移除）→ 从当前队列剔除，若正在播则跳到快照里的下一首。
- 空分组允许存在；空分组列表显示「从默认列表添加音频」引导。

  - 对应 SwiftUI：`.swipeActions` 或 `EditMode` + 自定义 leading `deleteDisclosure`；`.onMove` 排序；撤销用轻量 snackbar/`Undo`。

- 空态：默认列表空 → 「导入第一段音频」；分组空 → 「从默认列表添加音频」。

## 5. 核心组件：波形 Scrubber

### 5.1 结构
- 一排竖条（≈60 根），`flex` 等宽，间距 2，圆角 3。
- 未播放 `white 32%`，已播放 `white 100%`，当前 head 竖条 `scaleY 1.12`。
- 顶部刻度行：`0:00 / 中点 / 总时长`（11pt，65%）。
- 跟随 **药丸**：head 上方 `-30pt`，白底黑字 12/semibold，带下三角。
- **标记旗标**：黄 `#FFD15C` 竖线（覆盖波形高 +6）+ 顶部小旗（时间码 10/semibold）。
- （可选）**圆柄 knob**：26pt 白圆 + 3pt 半透明白描边，居中于 head（易拖版使用）。

### 5.2 竖条高度算法
`barHeight = H*0.14 + amp * H*0.80`（H=波形容器高，`amp∈[0.14,1]` 为归一化响度）。真机 `amp` 来自音频采样（见技术方案 §波形提取），原型为合成包络。

### 5.3 手势 / 震动 / 方向（核心交互）
- 命中区：整条波形（含上下留白），`DragGesture(minimumDistance:0)`。
- `onChanged`：`progress = clamp((x-origin)/width, 0,1)` → **实时**更新时间码/head/药丸/knob；播放中进入 scrub 态（暂停自走）。
- **方向语义**：右移 = 时间快进，左移 = 倒退；时间码实时跟随，右上角短暂显示 `􀯻快进`/`􀯶倒退` 提示（0.5s 淡出）。
- **微震动**：拖动跨过一根竖条（head index 变化）触发一次 `UIImpactFeedbackGenerator(.light)`（SwiftUI 可用 `.sensoryFeedback(.selection, trigger: headIndex)`）；到达两端触发 `.soft` 边界感；跨过标记点触发 `.medium`。加频率保护 + `prepare()` 预热。
- `onEnded`：`player.seek(to:)` 落定，退出 scrub 态。

| A 居中微控件(精修1) | 高80,`bottom:150` | 居中 play42 + 上下首19，标记药丸在上 | 经典留白 |

## 6. 状态与边界
- 播放/暂停、scrub 中、加载中（波形未就绪→骨架灰条）、空音库、导入失败、无标记。
- 到达结尾：停在 1.0，播放键回到 play；单曲/列表循环策略待定（§8）。
- 深色/浅色：播放页始终渐变底（白字）；音库页跟随系统浅/深。

---

## 7. 可访问性
- 波形 scrubber 暴露为 `accessibilityRepresentation` slider（`adjustable`），VoiceOver 上下轻扫 ±5s，播报 `mm:ss / 总时长`。
- 触感遵循系统开关；「减弱动态」时弱化视觉脉冲保留震动。
- Dynamic Type：标题/副信息支持缩放；特大时间码设上限避免溢出。
- 命中区 ≥ 44×44pt（微型 transport 用透明扩大命中区）。
